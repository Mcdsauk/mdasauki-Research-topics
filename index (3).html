          Import student registrations from a document

          Upload a class list, allocation sheet or form responses. Names, matric numbers, phone numbers, emails, topics and supervisors are extracted into a table for you to check before anything is saved.

          Use this when the document is a letter, a form or an irregular layout. Claude reads the whole text and returns each student's details.
          Which layouts work best

          Tables and spreadsheets with a header row work best, for example columns named Surname, Other names, Matric No, Phone, Babcock Email, Personal Email, Project Topic and Supervisor. A single "Name" or "Email" column is fine: names are split into surname and other names, and emails are sorted by domain. Documents written as "Name: …, Matric: …" blocks, one student after another, are also read. Google Form exports work directly: the Timestamp becomes the registration time, a "Name (Surname first, then other names)" column is split accordingly, one Email column is sorted into Babcock or personal by domain, and the Session column is kept, extra columns such as State of Origin are ignored, and a topic already registered by another student is flagged and can't be imported. If a student submitted more than once, the latest submission is used. For anything else, use Extract with Claude.
